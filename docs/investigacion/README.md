### 6. 🐍 Script de Generación de Gráficos

**Lenguaje:** Python 3.10+  
**Dependencias:** matplotlib, numpy, pandas, seaborn

**Funcionalidades:**
- 8 funciones individuales (una por gráfico)
- Función master `generar_todos_graficos()` ejecuta secuencia completa
- Exportación simultánea a PNG (300 DPI) y SVG
- Estilo profesional con paleta de colores consistente
- Directorio de salida: `visualizaciones/graficos/`

**Ejecución:**

## 🚀 Próximos Pasos Recomendados

### Fase 1: Validación de Datos (4-6 semanas)
**Responsable:** Equipo de investigación

**Acciones prioritarias:**
1. Contactar IPSE para censo ZNI actualizado ⚠️ **Crítico**
2. Solicitar cotizaciones formales a 3 proveedores equipos ⚠️ **Crítico**
3. Reunión con Electrificadora del Caquetá (tarifas, cobertura) ⚠️ **Crítico**
4. Verificar precio bolsa energía con XM ⚠️ **Crítico**
5. Descargar datos IDEAM Atlas Solar (series históricas)
6. Confirmar variables macroeconómicas con DANE y Banco República

**Entregable:** CHECKLIST_VALIDACION.md con estado ✅ en 20+ ítems críticos

### Fase 2: Refinamiento Financiero (2 semanas)
**Responsable:** Analista financiero

**Acciones:**
1. Construir modelo Excel con flujos de caja detallados (10 años)
2. Análisis de sensibilidad con 3 escenarios (pesimista, base, optimista)
3. Calcular punto de equilibrio operativo (break-even cash flow)
4. Proyección de necesidades de capital de trabajo

**Entregable:** Archivo Excel `modelo_financiero_energia_solar_caqueta.xlsx`

### Fase 3: Presentación Ejecutiva (1 semana)
**Responsable:** Equipo de comunicaciones

**Acciones:**
1. Crear presentación PowerPoint (15-20 slides)
2. Diseñar infografía de resumen de una página
3. Preparar pitch deck para inversionistas (formato PDF)
4. Video explicativo de 3 minutos (opcional)

**Entregables:**
- `presentacion_energia_solar_caqueta.pptx`
- `infografia_resumen_ejecutivo.pdf`
- `pitch_deck_inversionistas.pdf`

### Fase 4: Validación con Stakeholders (2 semanas)
**Responsable:** Director de proyecto

**Acciones:**
1. Reunión con Gobernación del Caquetá (presentar estudio)
2. Presentación ante Cámara de Comercio Florencia
3. Contacto con potenciales inversionistas/socios estratégicos
4. Feedback de empresas del sector (Celsia, EPM)

**Entregable:** Documento de retroalimentación y ajustes finales
